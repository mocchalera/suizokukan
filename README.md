# おえかきのうみ

**きみのえが、いきてる。** 白い紙に描いたふしぎな子を、線も色もそのまま、小さな海へ。

公開先: **https://umi.mocchalera.app**。ログイン不要。音声・広告・解析・自由チャットはありません。初回からオリジナルのおためし生物と遊べます。

## 家族での遊び方

1. スマホで「つくる」→ カメラ、写真選択、または「おためしのしゃしん」。白い紙に1匹を大きめに描くのがおすすめです。
2. 四隅のつまみで切り抜く範囲を調整。「紙のしろさ」で背景を調整し、消す／残すブラシ、Undo、リセットで修正できます。むずかしいときは「紙をのこす」で紙切り絵にします。
3. 動くプレビューを見ながら、名前（任意）、すいすい／ぷかぷか／ふしぎ、絵付きせいかくを選びます。頭が逆なら左右反転。「うみに はなす」で初めて保存・誕生します。
4. 海を触るとあわ。「おやつ」を選んで触ると、ごはんへ寄ってきます。ずかんで同じ子を探す・休ませる・戻す・切り抜き直す・削除できます。
5. PCで「みんなのうみ」→「つくる」→「家族をしょうたい」。QRまたはリンクをスマホで開き、ずかんから子を選びます。**「切り抜きだけ 送る」の確認後**に、そのルームだけへ転送します。

作成側の画面が画像を準備してから共有の海に登場します。作成側タブを開いたままにしてください。スマホでもルーム作成・表示・あわ／おやつ／呼ぶ操作ができます。共有の海の右上の「**ぜんめんに ひらく**」でそのタブが全画面になり、プロジェクター投影向けに海いっぱいに拡大します（Escキー、または「ぜんめんを とじる」で解除）。壁へのタッチ検知には対応しません。

## 写真・データを大切に

- **写真の送信はありません。** 原ファイルは変更せず、ブラウザ内で向きを解釈して最大1200pxに縮小。再調整用の縮小JPEGだけをこの端末のIndexedDBに保持します。元ファイルそのもののバックアップではありません。
- 境界につながる白い紙だけを除去します。線で囲まれた白い目・白い部分は残します。薄い鉛筆、影、線の切れ目では手動修正が必要です。AIで描き直しません。
- 家族ルームへ送るのは、確認済みの**メタデータなしPNG、任意名、泳ぎ・せいかく、色のしるし**だけです。原写真、EXIF、設定文は送りません。
- 招待は256bitの秘密を持つリンクです。秘密はURLの`#`で受け取り、画面表示時にURLから取り除いてsessionStorageに保存します。ルームIDだけでは閲覧・投稿・画像取得できません。招待リンクは家族以外へ渡さないでください。リンクを知る人は参加できます。
- ルームは作成から**6時間**。期限時にAPIアクセスを拒否し、Durable Object alarmで画像・ルームデータを削除します。Cloudflare側の障害時は物理削除が遅れる可能性がありますが、期限後アクセスは拒否します。作成者はいつでも終了・共有コピー削除できます。共有コピーの削除はスマホ内ずかんを消しません。
- 作成者の「いったん もどる」は接続だけを切り、作成者権限を同じタブのsessionStorageに残します。同じ招待リンクを開く／貼り付けると、共有コピーの削除・終了・画像準備を再開できます。作成者の秘密は招待URL・QRには含めません。タブを閉じて権限を失った場合は復元できません（ルームは6時間で失効）。参加者の「この端末は ぬける」は従来どおり参加情報も消します。
- 作成側が不在などで画像準備の応答が**30秒**以内に届かなければ失敗に移り、共有画像を消します。自動再送・待機期限の延長はしません。遅れた準備応答も受け付けません。重複防止のためID・設定・しるし・送信データのハッシュは終了／6時間の期限まで残り、20匹の枠に数えます。再送する場合は作成者が「共有から はずす」で失敗した共有情報を消してから、もう一度確認して送ってください。端末のずかんは残ります。alarmが遅延しても次の認証済みアクセスで期限を再確認し、期限後の画像は配信しません。
- ずかんは端末／ブラウザごとです。ブラウザデータ削除や端末紛失で消えます。「バックアップを保存」でときどき書き出してください。バックアップv1は切り抜きと設定のみで、原写真・家族の招待・AI設定文は含みません。読み込みは確認式・追加のみ・同じIDを上書きしません。
- 名前欄に本名や個人情報を入れないでください。削除は確認式で、その後は取り消せません。先にバックアップを推奨します。

## 上限

| 対象 | 上限 |
| --- | --- |
| 写真 | JPEG / PNG / WebP、15,000,000 bytes、4000万画素、辺16384px以内 |
| 縮小写真・画素処理 | 長辺1200px（画素処理はWeb Worker） |
| 切り抜きPNG | 512×512px以内、180,000 bytes（必要なら段階縮小） |
| 端末のずかん / 海 | 40匹 / 20匹（おためし生物を含む表示上限） |
| バックアップ | v1、10,000,000 bytes、40匹、URL/SVG/HTML/不正PNGを拒否 |
| 共有ルーム | 6時間、20匹、合計3.6MB、16接続 |
| 共有画像の準備待ち | 投稿から30秒。失敗後は画像削除、重複防止情報のみ保持 |
| ルーム作成 | サービス全体40件/UTC日、同一IP12件/UTC日 |
| ルームAPI / 投稿 | ルーム単位240件/分 / 30件/分 |
| WebSocket | 1接続60操作/分、500文字/操作、接続券は1回・30秒 |
| Jev | 有効化済み。全体最大50回/UTC日、同一IP10回/UTC日（上限値は50に丸め）。未接続・上限時はfallback |

利用量制限はアプリの安全弁であり、Cloudflare全体の請求上限を設定するものではありません。新しい有料プランには加入しません。R2/KV/公開バケットは使わず、SQLite Durable Objects 2クラスのみ使用します。

共有PNGはサーバーでCRC・構造に加えIDATのzlib展開、走査行サイズ、フィルター、パレット参照を検証してから保存・配信します。展開上限は画像寸法から算出し、最大1,049,088 bytesです。壊れた圧縮データや展開過大の画像は保存しません。原画のピクセルを書き直す処理ではありません。

## ローカル起動

Node.js 24で検証。依存はlockfile固定です。

```sh
npm ci
npm run build
npm run dev:api
# 別のターミナル（ホットリロードが必要なとき）
npm run dev
```

APIとビルド済みSPAは`http://127.0.0.1:8787`。Viteは`http://127.0.0.1:5173`でAPIを8787へproxyします。localhost以外のカメラはHTTPSが必要です。カメラ拒否時も写真選択・内蔵サンプル・簡易お絵描きを使えます。HEICは未対応です。JPEGで選択／変換してください。

```sh
npm run typecheck
npm test
npm run build
npm run verify:release
npx playwright install chromium webkit
# API起動後
npm run test:e2e
npm run test:smoke
```

E2EはChromium desktop/mobileとWebKit mobile。複数browser contextで実際のHTTP/WebSocket同期も検証します。出力は`test-artifacts/runtime`（Git除外）。`BASE_URL`で本番を指定できます。全E2Eはルームを5件作成・終了するため、同日12件/IPの上限に注意してください。テストは自分で作ったルームしか操作しません。反復検証は`npx wrangler dev --local --persist-to test-artifacts/runtime/qa-room-state`などの隔離ローカル環境で行い、本番の日次上限を回避・リセットしないでください。

## Jevは任意

**現在は有効化済みです（全体50回/UTC日、同一IP10回/UTC日）。** せいかくボタンだけで全機能を遊べます。未接続・上限・失敗時は選択式fallbackへ戻り、AI稼働中とは表示しません。

2026-09-22に公式`https://docs.typesafe.ai/llms.txt`を入口としてAPI/model/auth/schemaを確認。使用契約は`POST https://api.typesafe.ai/v1/systemone`、Bearer認証、`jev-1.13.0`。Choiceは列挙キーのcriteriaオブジェクト、Scoreは2つの説明を持つcriteria配列です。他社API・モデルへは切り替えません。

親が任意の設定文を入力・送信同意した誕生時にだけ、サーバー経由で1回呼び出します。上限160文字、個人情報を入力しない案内、URL・連絡先風文字列の拒否、enum検証、score clamp、3.5秒timeout、利用回数制限、古い応答の破棄を実装。エラーでも選択式のせいかくで保存・誕生します。画像や子の名前をJevへ送りません。

有効化は、所有者が承認した鍵を安全な入力経路から`npx wrangler secret put JEV_API_KEY`に渡し、承認済み予算で`JEV_DAILY_LIMIT`（現在50）を設定して再デプロイする手順です。鍵をコマンド引数、`VITE_*`、Git、ログに書かないでください。鍵の再発行・予算変更・無効化は所有者の明示承認が必要です。50を超える予算指定は予算実装（`worker/budget.ts`）で50に丸められます。鍵が存在するだけではlive成功の証明にならず、公式契約の再確認とlive試験で確認します。ローカルはGit除外済み`.dev.vars`を使用できます。

## 安全な本番デプロイ

1. `gh` / Wranglerの既存認証を使用。Cloudflareの対象zoneで、`umi.mocchalera.app`のDNS、ワイルドカードDNS、Worker/custom domain/routesの衝突を**読み取り確認**します。既存があれば置換せず`suizokukan.mocchalera.app`を同様に確認します。
2. `wrangler.jsonc`のcustom domainは選んだホストのみ。既存の無関係DNSやWorkerを変更しません。プラン不足の場合はプランを変更せず止めます。
3. typecheck/unit/build/e2e/release scanを実行し、タスク所有ファイルだけcommit。`git push origin main`を通常実行（force不可）。
4. `npm run deploy`。clean main、GitHub mainとHEADの一致、ビルドのcommit一致を検証してからWranglerで公開します。
5. `BASE_URL=https://umi.mocchalera.app EXPECTED_COMMIT=HEAD npm run test:smoke`、さらに本番E2Eの家族ルームを別contextで確認します。

`/api/health`と`/source.json`に非秘密commit/dirty/version、healthにCloudflare deployment version IDを出します。API未知routeはJSON404（SPA HTMLへ落としません）。CSP・no-referrer・no-store画像API・同一Origin制限を設定しています。Service Workerは使用せず、更新したHTMLを再取得します。

静的応答には`no-transform`を付け、Cloudflare Web Analyticsの自動beacon挿入を防ぎます。CSPの外部script許可やzone全体の設定変更は不要です。公開後smokeは解析スクリプト非混入も検査します。根拠: Cloudflare公式`https://developers.cloudflare.com/web-analytics/get-started/`。

不具合時はまず招待の新規共有を止め、作成者画面から自分のルームを終了します。コードの巻き戻しは、所有者確認のうえ検証済み修正/revert commitを通常pushし再デプロイします。既存Git履歴、他Worker、他DNSを削除しません。プロダクト全体の停止・custom domain削除は別途明示承認が必要です。

## 実装と検証

React + TypeScript + Vite、Canvas 2Dの12分割による控えめな尾揺れ、決定的ローカル移動。毎frameネットワーク同期はありません。バックグラウンドでは描画pause、dt clamp、20画像のキャッシュ、画像/RAF/stream/socket cleanup、reduced-motionに対応。

原画尊重と安全規約は`AGENTS.md`、実際の検証結果・未検証事項は`docs/implementation-status.md`。静的イラスト、合成fixture、スクリーンショットはこの実装用のオリジナルです。実際の子どもの絵・実機カメラで評価したとは主張しません。
